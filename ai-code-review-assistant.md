# AI Code Review Assistant

## What it does

Listens for GitHub `pull_request` webhook events. When a new PR is opened, it fetches the diff, sends it to OpenAI GPT-4o for analysis, and posts a structured review comment back on the PR — covering a summary, any bugs or security issues found, style suggestions, and a verdict (APPROVE / REQUEST_CHANGES / COMMENT).

## Trigger

HTTP POST webhook — register it as a GitHub webhook on your repository under **Settings → Webhooks**, listening for `Pull requests` events.

## Required Credentials

| Credential | n8n Type | Where to get it |
|------------|----------|----------------|
| GitHub Personal Access Token | `HTTP Header Auth` | GitHub → Settings → Developer settings → Personal access tokens → Fine-grained token with `pull_requests: write` |
| OpenAI API key | `OpenAI API` | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) |

## Required Setup

1. Create a GitHub **Personal Access Token** with `repo` or `pull_requests: write` scope.
2. In n8n, create an **HTTP Header Auth** credential:
   - Header Name: `Authorization`
   - Header Value: `token YOUR_GITHUB_TOKEN`
3. Register a GitHub webhook on your repository:
   - Payload URL: your n8n webhook URL (shown in the **GitHub PR Webhook** node)
   - Content type: `application/json`
   - Events: `Pull requests`
4. The diff is truncated to 8,000 characters — for very large PRs, consider splitting by file.

## How to Import

1. Open your n8n instance.
2. Click **Workflows** → **Add Workflow** → **Import from File**.
3. Select `ai-code-review-assistant.json`.
4. Assign your **HTTP Header Auth** credential (GitHub token) to both HTTP Request nodes.
5. Assign your **OpenAI API** credential to the **Review with OpenAI** node.
6. Activate the workflow and register the webhook URL in GitHub.

## Nodes Overview

| Node | Type | Purpose |
|------|------|---------|
| GitHub PR Webhook | `webhook` | Receives GitHub pull_request event payloads |
| Filter PR Opened | `if` | Only processes events where `action == "opened"` |
| Fetch PR Diff | `httpRequest` | Downloads the raw diff from GitHub's `diff_url` |
| Review with OpenAI | `openAi` | Sends diff + PR metadata to GPT-4o for structured review |
| Post GitHub Review Comment | `httpRequest` | Posts the AI review as a PR comment via GitHub API |

## Expected Output

A comment appears on the PR within seconds of it being opened:
